# Муж на час — демонстрационный проект для портфолио

**Работающая демоверсия:** [Открыть сайт на Vercel](https://portfolio-1-black-nu.vercel.app/) · production, без входа.

**Веб-интерфейс / демонстрация.** Адаптивный лендинг услуг: калькулятор работ, доступный диалог и демонстрационная форма. HTML, CSS, JavaScript; без серверной отправки заявок. Разработка с помощью ИИ и AI coding tools. [Автор и другие проекты](https://github.com/trollpom) · [Публичная CRM](https://github.com/trollpom/my_crm).

Современная обезличенная версия лендинга из архивного приватного репозитория `https://github.com/trollpom/project_1.git`.

## Структура и запуск

```text
index.html             Страница и контент
styles.css             Дизайн, адаптивная сетка и анимации
app.js                 Меню, калькулятор, диалог и демоформы
assets/                Сгенерированные фотографии, иконка и локальные шрифты
image-prompts.md        Промпты фотографий
```

Сайт статический: сборка и зависимости не нужны. Откройте `index.html` в браузере или запустите из корня `python -m http.server 8000` и перейдите на `http://localhost:8000`.

## Что изменено

- Новая тёплая палитра: лесной зелёный, светлый кремовый и терракота.
- Крупные заголовки, курсивные акценты, фотографии и векторные иконки.
- Все исходные фотографии удалены из поставляемых файлов; новые фотографии созданы встроенным генератором изображений.
- Реальное имя мастера заменено вымышленным персонажем Никитой. Аватары отзывов заменены буквенными иконками.
- Убраны фиктивные телефонные и мессенджерные ссылки, бизнес-разметка и неподтверждённые рейтинги. Отзывы явно отмечены как иллюстративные.
- Сохранены шесть направлений услуг и стартовые цены из исходника. Добавлен выбор работ с предварительной суммой и переносом списка в заявку.
- Анимации появления, состояния кнопок и карточек, мобильное меню, диалог заявки, FAQ. При `prefers-reduced-motion` анимации выключаются.
- Формы проверяют заполнение и номер телефона, затем показывают результат демонстрации. Никаких заявок, запросов к серверу, аналитики, cookies или сохранения введённых данных.
- Шрифты находятся в проекте: внешние сервисы шрифтов не нужны.

## Публикация

Готовые файлы расположены в корне репозитория `trollpom/portfolio_1`. Для статического хостинга команда сборки не нужна, каталог публикации — корень. Для GitHub Pages выберите ветку `main` и папку `/ (root)` в настройках Pages.

Репозиторий содержит только новую обезличенную версию. История исходного репозитория не переносится.

## Проверка

Проверены синтаксис JavaScript, уникальность ID, локальные ссылки и файлы, SVG-иконки, подписи полей, адаптивные правила и отсутствие оригинальных изображений в поставляемой версии. Выполнены проверки логики калькулятора, выбора услуги, открытия/закрытия диалога, мобильного меню и демоформ в изолированной модели DOM.

28.10.2026: production-версия Vercel ответила HTTP 200 без авторизации. В браузере проверены выбор розетки и смесителя (1 100 ₽), перенос списка и суммы в диалог заявки, открытие и закрытие диалога. Девять файлов сайта, включая изображения и шрифты, совпали с исходниками по хешу. Это проверка указанного сценария; реальные заявки не отправлялись.

Это демонстрационная версия. Чтобы собирать реальные заявки, нужно отдельно подключить обработчик формы, актуальные контакты и условия услуги.

## Развёртывание на Vercel

Проект связан с этим GitHub-репозиторием, production-ветка — `main`. Используется статическая публикация файлов из корня, без команды сборки и серверных секретов. Изменения, отправленные в `main`, запускают новый деплой. Старый Netlify не используется как основная ссылка портфолио.
